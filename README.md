# 码诗 · CodePoetry

&gt; 读诗如阅码，诗词代码化。

这是一个将古典诗词转译为现代编程语言的实验性仓库。  
在这里，**每一首唐诗宋词都是一个可运行的代码文件**——  
我们用 `if` 写转折，用 `while` 写重复，用 `catch` 写人生失意，  
用 `console.log` 留下唯一的、属于人类的中文。

---

## 如何阅读

1. **以眼读**：像看诗一样看代码的结构与韵律。
2. **以心译**：将代码逻辑还原为诗人的情感。
3. **以机诵**：运行它。终端输出的中文，便是诗人跨越千年的回声。

---

## 诗学原理

| 诗词元素 | 代码映射 |
|:---|:---|
| 起承转合 | 顺序 / 分支 / 循环 / 异常处理 |
| 叠字叠句 | `for` 循环、`while` 递归 |
| 对仗 | 对称的 `if/else`，平行的函数调用 |
| 用典 | 引入标准库、调用经典算法 |
| 留白 | 空行、未实现的 `TODO`、未捕获的异常 |
| 感叹 | `console.log("...")` 与注释 |

**唯一法则**：除注释与日志外，正文不得出现中文。  
代码必须是代码，不是披着语法糖的中文排列。
语言不限~。

## 提交规范

1. **目录放置**：`src/&lt;朝代拼音&gt;/&lt;作者全拼&gt;/&lt;作品英文名&gt;.&lt;后缀&gt;`
2. **正文铁律**：除注释与日志外，不得出现任何中文字符
3. **必须附元数据**：在作者目录下更新 `metadata.json`
4. **诗学注释**：在 PR 描述中说明「这句诗为什么用这行代码表达」
5. **可运行**：代码须能通过对应语言的解释器/编译器执行
