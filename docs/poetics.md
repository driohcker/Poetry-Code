# 诗学原理与转译规范

## 核心映射

| 诗词元素 | 代码映射 |
|:---|:---|
| 起承转合 | 顺序 / 分支 / 循环 / 异常处理 |
| 叠字叠句 | `for` 循环、`while` 递归 |
| 对仗 | 对称的 `if/else`，平行的函数调用 |
| 用典 | 引入标准库、调用经典算法 |
| 留白 | 空行、未实现的 `TODO`、未捕获的异常 |
| 感叹 | `console.log("...")` 与注释 |

## 铁律

1. **除注释与日志外，正文不得出现任何中文字符。**
2. 代码必须是代码，不是披着语法糖的中文排列。
3. 语言不限，但须能通过对应语言的解释器或编译器执行。

## 注释规范

- 文件顶部用注释写明诗题与作者。
- 关键代码行上方可用注释对应原诗句。
- 注释可使用中文，用于帮助读者理解诗与代码的映射关系。
